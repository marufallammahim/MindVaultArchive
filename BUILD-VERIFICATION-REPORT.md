## Release blocker

A real signed production APK cannot be generated until the repository owner creates or supplies a private keystore and adds these GitHub Actions repository secrets:
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

The Signed Android Release workflow intentionally fails if these secrets are absent. This prevents an unsigned or debug-signed APK from being mislabeled as a production release.

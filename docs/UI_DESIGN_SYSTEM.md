# UI Design System

## Brand

MindVault Archive uses a deep burgundy brand accent (`#5A0719`) with Material 3
color-scheme generation. Light and dark themes remain available and theme
selection persists locally.

## UI principles

- Keep primary note creation and search easy to reach.
- Use responsive Material 3 components and accessible labels.
- Preserve content space in the editor.
- Clearly communicate saving, failures and destructive actions.
- Never show fabricated sync or cloud status.

## Current gaps

AMOLED-specific theme, accent customization, typography controls, dashboard
personalization and a complete reusable MV component library remain future work.
